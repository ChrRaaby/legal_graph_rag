Remove the Streamlit UI; move eval artefacts to eval_history/

User request: the Streamlit app is obsolete, and the repo root had accumulated
56 eval_results_*.jsonl files plus 15 run logs.

STREAMLIT REMOVAL - app.py is now PURE RUNTIME, 3556 -> 2166 lines.
Deleted: every _render_* function, the module-level page code, the
Streamlit-only SQLite trace/eval tables, _eval_run_case, validate_citations,
and the sidebar CSS. Also removed the sys.modules Streamlit stubs from
server.py, eval_run.py, eval_compare.py and eval_scope_fixtures.py - importing
app no longer executes UI code or builds a runtime as a side effect, so
server._acquire_runtime() is now the single initialisation path (it previously
reused app.py's import-time build). @st.cache_resource on build_runtime became
functools.lru_cache, preserving the memoisation. Dependencies dropped:
streamlit, altair, pandas, neo4j_viz.

Method: verified FIRST that no UI symbol is referenced outside app.py and that
pandas/altair/neo4j_viz/sqlite3 are used only by the UI half; then performed
anchored, assertion-guarded surgery (scratchpad/strip_streamlit.py) that
refuses to run against a drifted file and asserts every runtime symbol survives.

WORKSPACE CLEANUP - eval artefacts now live in eval_history/:
56 run outputs, 15 run logs and the trajectory log moved; the 2 fixture
BASELINES moved with git mv so their history is preserved. New
app.eval_artifact_path() resolves a RELATIVE --output into that folder while
passing ABSOLUTE paths through untouched, so throwaway runs can still target
/tmp. Readers (/api/eval/runs, /api/eval/fixtures, ab_judge.py) check
eval_history/ first and fall back to the repo root, so an older checkout keeps
working. .gitignore ignores the folder's outputs and re-includes the two
tracked baselines. Documented in eval_history/README.md.

DOCS: CLAUDE.md and README.md no longer present Streamlit as the way to run the
project. The README's three known staleness bugs are fixed in the same pass -
tool table 13 -> 12 (with a note on the C3-pruned three), architecture diagram
shows Maskinrummet plus the scope gate, and the law table gains BAL and PBL.

Verified (17/17 sweep): all touched modules parse; zero streamlit references in
project code or deps; app.py imports cleanly with sys.modules["streamlit"] set
to None so any residual import fails loudly; eval_run CLI green; a new run
lands in eval_history/ and does not leak into the root; absolute --output still
bypasses the folder; /api/eval/{runs,fixtures,golden} and /api/architecture all
answer; A1 proof and F1 offline suite green; 56 replay assertions and Playwright
green.

Note: app.py.lean_experiment.bak (untracked, June, from the C5 lean-prompt
experiment) was moved to scratchpad/ rather than deleted - it is not in git, so
deletion would be irreversible.
